# LS Insight

## Sobre o projeto

Este projeto corresponde ao desenvolvimento **frontend do site institucional da LS Insight**, desenvolvido para apresentar a empresa, seus serviços e suas áreas de atuação.

O site é composto pelas seguintes sessões de páginas:

- **LS Insight** — apresentação institucional e soluções digitais.
- **LS Insight Academy** — conteúdos relacionados a cursos, treinamentos e capacitação.
- **LS Insight Consultoria Contábil** — serviços e soluções na área contábil.
- **LS Insight Consórcio** — soluções relacionadas a consórcios e planejamento patrimonial.
